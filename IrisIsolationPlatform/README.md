# Iris Isolation Platform

A full-stack iris segmentation platform with a React workbench, FastAPI REST API, OpenCV and optional U-Net processors, PostgreSQL metadata, Azure Blob Storage, Docker, and Azure Container Apps infrastructure.

## Repository

- `frontend/`: React 19, TypeScript, Vite, Tailwind CSS, drag-and-drop upload, comparison slider, confidence display, themes, and PNG download.
- `backend/`: FastAPI, SQLAlchemy, JWT validation, upload controls, audit events, rate limiting, storage adapters, and segmentation engines.
- `ml/`: U-Net training entry point and dataset guidance.
- `infra/`: Azure Bicep and deployment script.
- `docs/`: architecture and REST contract.

## Quick Start with Docker

```powershell
Copy-Item .env.example .env
docker compose up --build
```

Open `http://localhost:5173`. API docs are at `http://localhost:8000/docs` and liveness is at `http://localhost:8000/api/v1/health/live`.

Development authentication permits an implicit local developer identity. Production requires a Bearer JWT and must configure issuer, audience, and signing validation.

## Local Development

Frontend:

```powershell
Set-Location frontend
npm install
npm run dev
```

Backend (Python 3.11 or newer is required):

```powershell
Set-Location backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
uvicorn app.main:app --reload
```

This workstation did not have Python installed when the project was generated, so backend tests could not be executed locally. Once Python is available, validate with:

```powershell
python -m ruff check app tests
python -m pytest
```

## API

See [docs/api.md](docs/api.md). The OpenAPI document is generated by FastAPI at `/openapi.json` and the interactive documentation is available at `/docs`.

## U-Net

Install `pip install -e ".[ml]"`, train with [ml/train.py](ml/train.py), and set `IRIS_UNET_CHECKPOINT` to the resulting checkpoint. Production acceptance requires a documented, consented dataset and subject-disjoint evaluation; see [ml/README.md](ml/README.md).

## Security and Operations

- Never commit `.env`, model checkpoints, database files, or uploaded images.
- Replace development authentication before exposing the API.
- Keep Container Apps ingress HTTPS-only and restrict CORS to the deployed frontend origin.
- Use managed identities for Blob Storage, ACR, and Key Vault access.
- Use a shared distributed limiter such as Azure Managed Redis when scaling the API beyond one replica.
- Configure retention jobs for original images, extracted results, metadata, and audit logs according to applicable biometric privacy requirements.

## Azure Deployment

The Bicep template provisions Container Apps, PostgreSQL 17, Blob Storage, Container Registry, Key Vault, Log Analytics, and a user-assigned managed identity. Region/SKU preflight could not be completed during generation because the Azure deployment tool could not access the selected subscription; rerun availability and quota checks before deployment.

```powershell
$password = Read-Host "PostgreSQL administrator password" -AsSecureString
.\infra\deploy.ps1 -ResourceGroup rg-iris-dev -PostgresAdminPassword $password -Location uksouth
```

The checked-in parameters file contains a non-secret deployment placeholder. The script overrides it and never writes the supplied password to disk. After deployment, configure the production JWT issuer/audience and update CORS to the emitted web URL.
